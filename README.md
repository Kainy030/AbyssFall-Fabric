# AbyssFall

一个以**理智**与**感知**为核心的 Fabric 模组。

深渊不只是危险：随着 San 值下降，熟悉的方块、物品与环境会逐渐失真，而没有两个玩家会
看到同一个深渊。San 衡量的不是你还能撑多久，而是这个世界你还有多少能够相信。

## 已实现的内容

以下功能在 1.21.11 上均已实现并经真实环境验证，正在逐步迁移到 26.2：

- **San 系统** —— 项目的地基。每位玩家携带一个理智读数与个人上限，服务端权威、随存档
  持久化、死亡不重置、只同步给本人。San 被刻意设计成**连续参数**而非分档状态机：
  0%～100% 之间每一点都是不同的处境，跌破某条线一次就足以触发对应的变化。
- **三层信息可见性** —— 玩家在游戏内永远只能得知百分比，绝不会看到底层数值。这是玩法
  设计而非技术限制：系统内部读真实比值，玩家的感知是粗糙的，而「能知道多精确」本身就是
  可以争取的游玩内容。
- **两种 HUD 读数** —— 十格图标行（默认，与饱食度并列）与紫色百分比进度条，由**认知窥镜**
  切换。带完整的低理智抖动、失去时的一次颤动、恢复时的行波与回满闪光。
- **认知窥镜** —— 手持右键切换读数形态，并短暂强制显示。
- **理智计数器** —— 开发者专用调试道具，显示精确数值，默认不注册。
- **精神崩溃 / 精神饱满** —— 一对方向相反的药水效果，每 10 秒按上限的百分比扣除或回复
  理智，五级分别为 1% / 2% / 4% / 8% / 12.5%。和平难度会拦下崩溃，但不拦饱满。
- **深渊之花 / 深渊污泥** —— 凋零玫瑰可以种在深渊污泥上，用骨粉催熟即献祭玫瑰、结出
  深渊之花。这是获得此花的唯一制作途径。
- **战利品注入** —— 深渊之花会出现在 18 张高价值结构宝箱表中，概率可配；持有「深渊
  探索者」效果时必定额外获得一朵。
- **配置系统** —— `config/abyssfall.json`，按功能分块，缺字段自动回落默认值，坏文件会
  被备份而不是丢弃。为「配置项会长到很多」而设计。
- **三个成就**、**测试协议弹窗**（启动时的双语告知机制）。

## 构建

```bash
./gradlew build          # 编译并打包
./gradlew releaseJars    # 汇总三个发布产物到 build/release/
```

需要 JDK 25。产出 `abyssfall.jar`、`abyssfall-source.jar`、`abyssfall-doc.jar`。
