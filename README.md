# AbyssFall — Minecraft 1.21.11（已停止维护）

> **这个分支不再接受新功能，也不再修复缺陷。**
> 开发已经全部转移到 [`main`](../../tree/main)，目标版本是 **Minecraft 26.2**。

一个以「理智」与「感知」为核心的 Fabric 模组。深渊不只是危险：随着 San 值下降，
熟悉的方块、物品与环境会逐渐失真，而没有两个玩家会看到同一个深渊。San 衡量的不是
你还能撑多久，而是这个世界你还有多少能够相信。

## 这个分支是什么

`1.21.11` 分支保存的是本项目在 Minecraft 1.21.11 上的最终状态，作为存档保留：

| 项 | 值 |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.3 |
| Fabric API | 0.141.6+1.21.11 |
| Loom | 1.17.19（`net.fabricmc.fabric-loom-remap`） |
| 映射 | Mojang 官方映射 |
| Java | 21 |
| 最后一个发布版本 | [`v0.5-Dev`](../../releases/tag/v0.5-Dev) |

已实现的内容——San 系统、配置系统、HUD 两种读数、认知窥镜、两个理智类药水效果、
战利品注入、三个成就——在这个版本上都是可用的，用户也已在真实环境中验证过。

## 为什么停止维护

Minecraft 从 **26.1** 起不再混淆代码，Fabric 也随之停止维护第三方映射。这不只是
一次版本号变更：构建方式、渲染管线与部分 API 的形态都变了，同一份源码无法同时服务
两个版本。与其让两条线互相牵制，不如把 1.21.11 定格在它完整可用的样子。

## 还想用 1.21.11 怎么办

- **直接下载**：[Releases](../../releases) 里的 `v0.5-Dev` 是这一版的最后构建。
- **自行构建**：检出本分支后 `./gradlew build releaseJars`，产物在 `build/release/`。
  需要 JDK 21。
- **继续修改**：欢迎 fork。本项目是 GPL-3.0-or-later，你可以在遵守许可的前提下
  自由地接手它。

## 想找 26.2 的版本

切到 [`main`](../../tree/main)。项目文档（`HANDOFF.md` 与 `REFERENCE.md`）也在那边
持续更新；本分支的两份文档描述的是 1.21.11 时期的状态，刻意不再修改。
